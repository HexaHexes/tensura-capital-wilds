# Tensura Capital: Wilds

Capital cities for the wild races - Goblins, Lizardmen and Aquatic folk - registered into the Tensura Faction Spawn ecosystem.

## What it does

Registers the capital(s) for: "goblins", "lizardman", "aquatic". Once registered, the spawn mod picks them up automatically: a player who first picks (or reincarnates into) one of these races is placed at the nearest registered capital to the world spawn.

Install like any mod, alongside Tensura Faction Spawn.

## Dependencies

| | Mod | Why |
|---|---|---|
| Required | Minecraft | - |
| Required | NeoForge | - |
| Required | Tensura Faction Spawn | Owns the central capital tags and arrival behaviour |
| Required | Tensura: Reincarnated | Bundled worldgen references Tensura biomes |
